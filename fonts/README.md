# Fonts

Drop a bold condensed font here for the headline look, e.g. **Anton** or **Oswald Bold**
(both SIL OFL, free for commercial use, from Google Fonts):

- `fonts/Anton-Regular.ttf`
- `fonts/Oswald-Bold.ttf`

If neither exists the engine falls back to a system font (DejaVu Sans Condensed Bold, Impact)
and prints a warning. Add other fonts by listing them in the look's `fonts` array.
